# javascript-lotto-precourse

# 프리코스 2주차 미션 - 로또
----------------

## 기능 목록


### 주의 사항
1. depth를 최대 2까지만 허용
2. 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현 
3. else를 지양 (if 조건절에서 값을 return하는 방식을 사용하면 else를 사용하지 않아도 됨)
4. Lotto 클래스 내부에 numbers 이외의 필드(인스턴스 변수)를 추가할 수 없음 
5. numbers의 접근 제어자를 변경할 수 없음
6. Lotto의 패키지를 변경할 수 있음 



### 1. 사용자 입력 저장

- 로또 구입 금액 입력 받기
    - 구입 금액에 해당하는 만큼 로또 발행
    - 로또 1장 당 1,000원 
    - 입력값이 1000 단위가 아닌 경우 예외처리 할 것 

- 당첨 번호 입력 받기
    - 중복되지 않는 숫자 
    - 쉼표로 번호 구분

- 보너스 번호 입력 받기
    - 당첨 번호와 중복되지 않을 것



### 2. 로또 발행

- 중복되지 않는 숫자 6개 뽑기



### 3. 로또 번호와 당첨 번호 비교 
    
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원



### 4. 수익률 계산

- (당첨 금액 / 총 구입 비용) * 100



### 5. 실행 결과 출력

- 발행한 로또 수량 출력

- 로또 수량 별 번호 출력
    - 로또 번호는 오름차순으로 정렬

- 당첨 내역 출력 

- 수익률 출력
    - 소수점 둘째 자리에서 반올림 



### 6. 예외처리 

[사용자 입력]
- 로또 범위가 1~45 범위 사이를 벗어난 경우
- 구매 금액이 천 단위가 아닌 경우
- 당첨 번호를 6개 미만/초과로 입력한 경우 
- 당첨 번호에 중복 숫자가 들어간 경우
- 보너스 번호와 당첨 번호가 중복되는 경우 
- 구매 금액이 숫자가 아닌 경우


### 7. 테스트

[입력 및 기능]
1. 당첨 번호가 쉼표로 잘 구분 되는지 확인 
2. 입력한 금액에 따른 로또 개수가 잘 도출되는지 확인
3. 로또 개수만큼 로또가 출력 되는지 확인
4. 당첨 번호와 로또 번호 일치에 따른 당첨 통계가 잘 도출되는지 확인 
6. 로또 번호가 중복이 없는 6개의 숫자인지 확인
7. 수익률 계산이 정확한지 확인 
8. 수익률이 소수점 2번째 자리에서 반올림 되었는지 확인


[예외 발생]
1. 로또 범위가 1~45 범위를 벗어난 경우 예외가 발생한다.
2. 구매 금액이 1,000원으로 나누어 떨어지지 않는 경우 예외가 발생한다.
3. 구매 금액이 숫자가 아닌 경우 예외가 발생한다.
4. 구매 금액이 입력되지 않은 경우 예외가 발생한다.
5. 구매 금액이 1,000원보다 작은 경우 예외가 발생한다.
6. 당첨 번호가 6개 미만인 경우 예외가 발생한다.
7. 보너스 번호와 당첨 번호가 중복되는 경우 예외가 발생한다.
8. 보너스 번호가 1~45 사이의 숫자가 아닌 경우 예외가 발생한다.
